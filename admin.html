módulo admin carregado > nenhum administrador cadastrado

A variável ADMIN_SETUP_KEY não está definida. No Netlify, abra Site configuration → Environment variables, crie ADMIN_SETUP_KEY com um texto secreto de 16+ caracteres, publique de novo e recarregue esta página.

A chave é o valor de ADMIN_SETUP_KEY no Netlify: só quem controla o site consegue criar o administrador. A senha precisa ter 10+ caracteres.
